- `POST /clientes`
- `GET /clientes/{id}`
- `PUT /clientes/{id}`

## Veículos
- `GET /veiculos`
- `POST /veiculos`
- `GET /veiculos/{id}`
- `PUT /veiculos/{id}`

- `POST /orcamentos`
